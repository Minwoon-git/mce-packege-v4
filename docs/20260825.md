# MCE 패키지 방향성 논의 질문지

## 1. 작업 우선순위

**대상 작업**

- 패키지 구조 다듬기
- 크롬 익스텐션 구조 변경 (서버 이전 + 웹스토어 배포)
- Data 360 연동

**질문**

> 고객사 적용(실사용)을 전제로 할 때, 세 작업의 **진행 순서를 어떻게 가져가야 할지**

## 2. MCE+/MC NEXT 전환 시 차별점

- Data 360 활용 확대 시 차후 MCE+ / MC NEXT로 넘어가는 흐름 예상
- MC NEXT는 AI 캠페인 생성 기능이 플랫폼에 기본 내장 예정 → 현 패키지 기능과 중복 발생

**질문**

> 차후 MCE+ / MC NEXT로 넘어가는 흐름일 시, 가져가야 할 차별점은 무엇인지

## 3. 질문 — 추가 기능 항목

**후보 2안**

- **대시보드 활용 고도화** — 현행 인사이트(요약)를 원인 진단 + 개선 캠페인 초안 생성까지 확장
- **AI 선제안** — 데이터 변화를 감지해 AI가 먼저 캠페인을 제안 (슬랙 or 챗봇)
