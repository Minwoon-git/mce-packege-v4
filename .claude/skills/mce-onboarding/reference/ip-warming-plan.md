# IP 워밍 권장 일정 템플릿 (텍스트 플랜)

전용 IP를 **신규로 받은 경우** 발신 평판을 쌓기 위해 발송량을 점진적으로 늘리는 운영 프로세스.
**API로 자동 수행할 수 없다** — 아래 표는 워커가 리포트에 **출력만** 하는 권장 플랜이다(리마인더 등록 안 함).

## 표준 4주 램프 (일 단위)

| 기간 | 일일 발송량(권장 상한) | 대상 우선순위 |
|---|---|---|
| Day 1 | ~50 | 최근 30일 오픈/클릭한 최우량 인게이지 고객 |
| Day 2–3 | 100 → 500 | 고인게이지 세그먼트 |
| Week 1 (Day 4–7) | 1,000 → 5,000 | 오픈율 높은 활성 고객 |
| Week 2 | 10,000 → 50,000 | 활성 고객 점진 확대 |
| Week 3 | 100,000 → 250,000 | 준활성 포함 |
| Week 4+ | 전체 발송 전환 | 전체 구독자 |

> 실제 수치는 계정의 총 발송 규모·세그먼트 크기에 맞춰 조정한다. 위는 일반 권장 기본값이다.

## 워밍 중 운영 수칙

1. **인게이지 순서로**: 가장 잘 여는 고객부터 → 점차 비활성으로 확대. 평판을 빠르게 올린다.
2. **하드바운스/스팸 모니터링**: 바운스율·스팸신고율이 급등하면 발송량을 전 단계로 되돌린다.
3. **일관된 발송 주기**: 매일 비슷한 시간·비슷한 양으로. 급등락은 평판에 악영향.
4. **콘텐츠 품질**: 워밍 기간엔 반응이 확실한(가치 높은) 콘텐츠만 발송.

## 선행 마일스톤 (워밍 시작 전 완료 권장)

| 마일스톤 | 권장 시점 |
|---|---|
| 도메인 인증(SAP/SPF·DKIM) 완료 | 워밍 시작 **D-7** |
| CAN-SPAM 물리 주소 등록 | 워밍 시작 **D-7** |
| 수신거부/프로필 센터 확인 | 워밍 시작 **D-7** |
| 최우량 인게이지 세그먼트 준비 | 워밍 시작 **D-3** |

> 이 마일스톤도 리포트에 **표로 출력만** 한다. 실제 리마인더는 등록하지 않는다(정책: 텍스트 플랜만).
