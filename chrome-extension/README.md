# MCE Bot — Chrome 확장

실제 MCE(SFMC) 화면 위에 챗봇을 팝업(모달)으로 띄우는 Chrome 확장.
SFMC는 `frame-ancestors` 정책으로 외부 페이지에서의 iframe 삽입을 차단하므로,
반대로 **MCE 페이지 위에 챗봇을 오버레이**하는 방식. 이미 로그인된 MCE 세션 그대로 사용.

## 구조

```
MCE 페이지 (mc.exacttarget.com)
   └─ content.js  — 우하단 🤖 버튼 + 챗봇 패널 (Shadow DOM, 페이지 스타일과 격리)
        │  chrome.runtime Port
        ▼
   background.js — localhost:3456 web-bridge와 통신 (SSE 중계, 페이지 CSP/CORS 우회)
        │
        ▼
   web-bridge/server.js — claude CLI 실행 (스킬·워커·SFMC MCP)
```

## 설치 (1회)

1. `web-bridge` 서버 실행 확인 — `web-bridge\run-web.cmd`
2. Chrome → 주소창에 `chrome://extensions` 입력
3. 우상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더(`chrome-extension`) 선택
5. MCE(`mc.exacttarget.com`) 접속 → 우하단 **🤖 버튼** 클릭

## 기능

- 플로팅 버튼(로봇 캐릭터) ↔ 챗봇 패널 토글 — MCE 화면을 가리지 않는 우하단 팝업. 버튼 이미지는 `fab.png`(512px 투명 PNG) 교체로 변경 가능 (v1.11.0~, `manifest.json`의 `web_accessible_resources`에 등록돼 있어야 함)
- **결과만 표시** — 처리 중에는 "처리 중…" 표시만 하고 도구 실행 등 중간 과정 비노출, 완료 시 최종 답변만 출력. 버튼 상태 점으로 상태 확인(초록=대기, 노랑 깜빡임=처리 중)
- **대화 내역** — 헤더의 시계 아이콘으로 이전 대화 목록 확인, 클릭 시 해당 대화를 열어 맥락 그대로 이어가기(각 대화가 자기 Claude 세션 유지), 개별 삭제 가능 (최근 30개 보관)
- 대화 연속성 — localStorage 보존으로 새로고침·페이지 이동에도 유지. 처리 중 패널을 닫았다 다시 열어도 진행 말풍선 유지
- **챗봇 ON/OFF(v1.15.0~)** — Chrome 툴바의 MCE Bot 아이콘을 클릭할 때마다 챗봇 전체 켜기/끄기 토글. OFF면 플로팅 버튼·패널이 모든 MCE 탭에서 즉시 사라지고 아이콘에 빨간 `OFF` 배지가 표시됨. 상태는 저장되어 새로고침·브라우저 재시작에도 유지 (대화 내역은 지워지지 않음). 툴바에 아이콘이 안 보이면 퍼즐(🧩) 메뉴에서 MCE Bot을 고정
- **드래그 이동** — 버튼·패널(헤더) 드래그로 위치 이동. 위치는 탭 단위로 기억(같은 탭에서는 페이지 이동·새로고침에도 유지, 새 탭은 항상 우하단 기본 위치)
- **크기 조절** — 패널 가장자리/모서리 8방향 드래그(크기는 영구 보존). 헤더의 최대화 버튼 ↔ 기본 크기(448×700) 복원 토글, 복원 시 크기 변경 전 위치로 복귀
- **성과 대시보드 내장 뷰(v1.14.0~)** — 헤더 📊 버튼으로 패널 안에서 성과 요약을 바로 확인 (새 탭·별도 페이지 없음). **기간 필터(7/14/30일)** + KPI 카드 4종(발송·오픈율·클릭율·바운스율, 이전 동일 기간 대비 ▲▼) + 발송/오픈 추이 차트(**hover 시 일자별 수치 툴팁**·날짜 눈금) + 저니별 성과 표 + 인사이트 카드(추천 액션 버튼 → 클릭 시 해당 요청을 채팅으로 전송). 데이터는 `/api/dashboard-data`(SENDLOG_History 집계 JSON)를 즉시 조회 — **Claude 호출 없음(무비용·1초)**. 실데이터 파일이 없으면 샘플 데이터(⚠ 표시)로 표시
- **콘솔형 와이드 레이아웃(v1.16.0~)** — 패널 폭이 900px 이상(최대화 또는 수동 확대)이면 **왼쪽 사이드바**(성과 대시보드/대화/대화 내역, 브랜드 블루)가 나타나고 헤더의 화면 전환 버튼은 사이드바로 이동. 대시보드는 KPI 4열 + 인사이트 우측 레일의 2단 그리드로 재배치. 기본 크기에선 기존처럼 상단 아이콘 + 세로 스택. 홈 화면 추천 버튼은 아이콘+설명 카드형으로, 이모지·그라데이션 버튼은 절제된 스타일로 정리(성과 대시보드 뷰 포함). 이전 디자인 백업: `.claude/_backup_design_20260827/`
- **파일 첨부 — 드래그&드롭 또는 입력창 왼쪽 + 버튼(v1.12.0~)** — 패널에 파일을 놓으면 web-bridge가 저장(정의서 xlsx/xlsm/csv → `campaign_definitions\`, txt/sql/md/json/jpg/png → `uploads\`)하고 입력창 위에 📎 칩으로 표시. 전송 시 메시지 앞에 `📎 첨부 파일: <경로>`가 자동으로 붙어 "정의서 직접 첨부 → 저니 생성" 흐름이 챗봇만으로 완결됨. 최대 20MB, 그 외 형식은 거부
- **산출물 다운로드 링크(v1.10.0~)** — 답변에 정의서(xlsx)·분석 리포트(pptx 등) 경로가 나오면 **📎 파일명** 칩으로 바꿔 클릭 한 번에 다운로드. web-bridge의 `GET /api/file` 이용, `campaign_definitions`·`reports` 폴더의 문서 확장자만 허용 (이전 대화를 다시 열어도 링크로 표시됨)
- **SFMC 재인증 버튼(v1.15.1~)** — 답변 중 SFMC 인증 만료(session invalid/revoked)가 감지되면 말풍선 아래 "🔐 SFMC 재인증" 버튼 자동 표시. 클릭하면 web-bridge가 콘솔 창을 띄워 `claude mcp login`을 실행하고 브라우저에 OAuth 로그인 창이 열림 — 로그인 후 요청을 다시 보내면 됨 (터미널 작업 불필요)
- **인증 배너(v1.16.1~)** — 패널을 열 때 인증 상태를 확인해(`GET /api/mcp-status`), 인증이 필요하면 상단에 🔐 배너+재인증 버튼 표시. 재인증이 완료되면(10초 간격 폴링 감지 또는 다음 응답에서 정상 확인) 배너가 자동으로 사라짐
- **상태 점 3색(v1.16.2~)** — 헤더 상태 점과 플로팅 버튼 점이 🟢 대기 중 / 🟡 처리 중 / 🔴 **연결 필요**(SFMC 인증 필요)로 표시. 인증 배너와 같은 신호로 동기화되어 재인증 완료 시 자동으로 초록 복귀. 페이지 로드 시(패널 열기 전)부터 확인하고 5분 간격으로 갱신(v1.16.3~)
- 중지(⏹) — 서버의 claude 프로세스 트리를 종료하고 "⏹ 요청을 중단했습니다" 안내 표시
- 마크다운 렌더링(표·코드블록·링크) · 새 대화(+) · 라이트/다크 모드 자동 대응 (OS 설정 따름)
- 글꼴 내장 — Noto Sans KR(가변 폰트, `fonts/`)을 확장에 포함해 어떤 PC에서든 동일하게 표시. 다른 글꼴로 바꾸려면 `fonts/`의 woff2·`fonts.css`를 교체하고 `content.js`의 font-family 스택 첫 항목 수정

## 계정 게이트 (버튼 노출 조건)

- 시작 시 web-bridge의 `GET /api/config`에서 `allowedAccounts`(허용 BU 이름 목록)를 조회
- **허용 BU 이름이 MCE 상단 헤더(뷰포트 상단 150px 가시 영역)에 실제로 보일 때만** 🤖 버튼 노출 — BU 전환 드롭다운에 숨겨진 다른 BU 이름은 화면 밖/0크기라 오탐하지 않음
- **서버 미응답 시 버튼 미노출**(fail-closed, v1.8.4~) — 서버 없이는 봇이 동작 불가하므로 아예 숨김. 버튼이 안 보이면 먼저 `web-bridge\run-web.cmd` 실행 여부 확인
- 목록이 비어 있으면(게이트 미설정) 모든 MCE 화면에서 노출
- 판정 결과는 콘솔 로그 `[MCE Bot vX.Y.Z] ...`로 확인 가능 (게이트 통과 시 매칭 요소도 로그)

## 유의 사항

- 이 확장은 **web-bridge 서버가 켜져 있는 PC에서만** 동작 (localhost 통신)
- MCE 페이지를 읽거나 조작하지 않음 — 오버레이 UI만 추가
- 확장 업데이트(파일 수정) 후에는 `chrome://extensions`에서 새로고침(↻) 필요 — 버전은 콘솔 로그의 `[MCE Bot vX.Y.Z]`로 확인
